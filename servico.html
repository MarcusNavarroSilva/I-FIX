Sobre o projeto

Este site foi desenvolvido como parte do curso de qualificação profissional em Web Design Front-End, realizado no SENAI Frederico Jacob, pela primeira turma de 2026. Ao longo da formação, adquirimos conhecimentos fundamentais em HTML e CSS, utilizando o Visual Studio Code (VS Code) como ferramenta principal para a criação de páginas web bem estruturadas, organizadas e com design moderno e responsivo. Durante o curso, também desenvolvemos habilidades na organização de arquivos e na aplicação das etapas de planejamento e desenvolvimento de websites, sempre com foco na prática dos conteúdos aprendidos. Este projeto representa a aplicação desses conhecimentos, por meio da criação de um site voltado para manutenção de celulares iPhone, priorizando uma navegação intuitiva, clara e visualmente agradável. Além do aprendizado técnico, o trabalho em grupo contribuiu para o desenvolvimento de competências importantes, como colaboração, organização e raciocínio lógico, essenciais para a área de tecnologia. A seguir, você pode conhecer os integrantes do grupo e acessar suas informações de contato.
